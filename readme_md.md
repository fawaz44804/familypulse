# Family Pulse | نبض الأسرة

> **One Tap Daily Well-Being Dashboard & Hardware Concept for UAE Homes**

Family Pulse is a web application and hardware prototype concept designed to track daily emotional rhythms within households with zero friction. Built with a focus on family privacy, multi-generational accessibility, and Arabic language support, it allows household members to log their daily mood with a single tap.

---

## ✨ Features

- **One-Tap Daily Check-In**: Select your role (Parent, Teen, Child, Grandparent) and log your feeling with a single icon tap.
- **Bilingual Interface**: Seamless instant toggle between English and Arabic (`RTL` support).
- **Live Family Score**: Aggregates entries into a single 0–100 Pulse score with progress gauge visualizations.
- **Weekly Trend Analytics**: Line chart breakdown showing daily mood shifts across the week powered by Chart.js.
- **Smart Recommendations Engine**: Rule-based action cards for parents when persistent fatigue or mood dips are detected.
- **AI Narrative Summaries**: Simulated weekly empathetic summaries based strictly on anonymous role aggregates.
- **Living Room Hardware Simulator**: Interactive simulation of an ESP32 micro-controller tabletop device with LED feedback.
- **Privacy by Design**: Guaranteed camera-free, audio-free, and local offline engine support.

---

## 🛠️ Tech Stack

- **HTML5** & **Vanilla JavaScript (ES6)**
- **Tailwind CSS** (via CDN)
- **Chart.js** (Data visualization)
- **FontAwesome** (UI icons)

## 🚀 Quick Start / Deployment on GitHub Pages

Because Family Pulse is built as a lightweight single-file application, you can host it live for free via **GitHub Pages**:

1. Push this repository to GitHub.
2. Go to repository **Settings** $\rightarrow$ **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**.

Your live URL will be ready at `https://<your-username>.github.io/<repository-name>/`.
